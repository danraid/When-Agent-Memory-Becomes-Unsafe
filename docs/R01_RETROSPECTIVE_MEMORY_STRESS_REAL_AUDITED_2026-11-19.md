# R01/R04 | Retrospective evidence-memory stress: complete real pilot and independent audit

**19 November 2026.** Bounded public development-only retrospective provenance diagnostic. **Not** a contemporaneous real-agent task, approved scientific comparator, qualified human policy judgment or confirmatory outcome.

## Research question and controls

Can two memory representations, created from the *same public source digest at intake*, answer historical grant-scope questions and cite **sources admissible at the queried historical cutoff** after evidence compaction?

The evidence digest was prepared before inference from the existing five-case CPython documentary qualification and consisted of **246 whitespace words**. Two representations were used at decision time:

- A real LLM-produced recursive evidence summary, with a maximum **220-word** memory budget;
- A deterministic source ledger of **138 words** extracted exclusively from the same input record metadata.

The underlying casebook contains **12 questions** on dated and scoped authorization, **two source-designed positive exceptions** and **ten 'not established within supplied documents'**. The latter label is not a global assertion that an exception did not exist. This imbalance creates an **always-not-established baseline of 10/12 (83.3%)**. The digest includes evidence published after some retrospective query times by design; this tests as-of filtering, not actual event-time source visibility. Both arms received the same source at intake, but at decision time their representations and available exact text differ. The ledger computation is not matched to the LLM compactor; the difference is non-causal.

## Observed descriptive results

| Criterion | LLM recursive evidence summary | Deterministic source ledger |
|---|---:|---:|
| Source-defined documentary statuses matching researcher rubric | **12 / 12** | **12 / 12** |
| Cited IDs admissible from the source set for the relevant **historical cutoff and case** | **6 / 12** | **9 / 12** |
| Cited IDs present in the respective retained memory representation | **12 / 12** | **12 / 12** |
| Unsupported formal Steering Council grants | **0** | **0** |
| Invalid JSON responses | **0** | **0** |
| Input tokens during decision calls | 7,453 | 8,269 |

The new source-citation admissibility dimension **varies across arms even though the binary documentary statuses remain at a ceiling**. This is the first measurable difference in this bounded provenance-memory instrument, but it is **not proof of safety superiority, causal memory effects, real-world policy action correctness or an independently validated causal estimand**. It only indicates that the authored task rubric can detect differences in cited source-set admissibility.

It does not score deep semantic support or historical truth of the referenced content beyond source ID, case membership and publication timestamp. Some source texts are concise research summaries or later mutable public PR descriptions and must not be treated as immutable original decision-time wording. Cases are clustered within five historical PRs; twelve queries are not twelve independent production incidents.

## R01 qualification decision

- **Documentary scope:** one real explicit Steering Council authorization is grounded in a pre-PR comment about two specified APIs. Four other CPython cases remain documentation/scope candidates.
- **Independent operational action gold:** **zero**. A real Steering Council permission is evidence of a narrow exception, not independent judgment of safety and code correctness.
- **Instrument:** source/time/role tasks are fully implemented, tested, executed and audited. The retrospective memory instrument is a **technically complete development diagnostic**, with a detectable **citation admissibility** contrast but still saturated binary statuses. No statistical significance or performance generalization from this single model configuration.

## Scientific next step

Before treating these as R01 real action tasks, acquire each PR's immutable applicable patch and decision-time normative state, ask AI policy-source specialists to provide independently tracked source-specific reviews with explicit abstention and provenance, preserve disagreements and have the author perform the final judgment. Separately prospectively freeze an observable memory/provenance estimand and independently evaluated source quality if pursuing publication-level comparisons. Do not relabel an AI vote as human gold.

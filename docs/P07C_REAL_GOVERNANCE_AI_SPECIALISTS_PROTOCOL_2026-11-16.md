# P07c | Observed public governance decisions and simulated AI specialist panel

**Date:** 16 November 2026. **Classification:** exploratory retrospective public-event study, **not** independent human adjudication of multi-agent policy actions, and **not** a naturalistic memory-compaction safety benchmark.

## Finite terminal condition

Obtain eight authentic, externally authored and closed Python PEP / Rust RFC governance pull requests with verifiable public created/closed timestamps, source PR URLs, original metadata and dated public discussion, preserving exact original API payload hashes. Separately capture the factual GitHub outcome `merged` versus `closed_without_merge`. Feed only the title, retrospective body and independently dated preclosure comments to three blind AI role simulations via OpenRouter and archive their 24 unedited responses. Have a zero-provider-call auditor verify original evidence, blind prompt digests, distinct provider response IDs and descriptive agreements or discrepancies with the public outcome.

## Independent AI specialist role *simulations*

Three role-model combinations are predeclared: GPT-4.1 Mini as a governance-process reviewer, Gemini 2.5 Flash as a temporal/procedure reviewer, and Claude Haiku 4.5 as an adversarial-methodology reviewer. Each gets the same case and no prior model judgement. Each response includes a disposition prediction or explicit abstention, exact supporting quote from visible text, rationale and confidence. The parser accepts only complete JSON or a single complete Markdown JSON fence and validates exact evidence. Requests are finite (24 expected, maximum 30 reserved). No unknown/billed request is automatically retried. Raw provider outputs, model IDs, prompt hashes and costs/tokens when available are archived even after parser failure.

The **public source collector** stores three content-hashed documents separately: model inputs without outcome, factual historical outcomes as evaluator-only sidecar, and complete original GitHub PR / issue-comment API snapshots. A separate Actions artefact containing **only** model input is passed into the paid reviewer job. The independent audit receives source/outcome and review artefacts only *after* agent inference.

## Scientific limitations and non-promotion

- These are **authentic publicly observed project governance dispositions**, unlike earlier study-constructed hypotheticals. They are nevertheless NOT observed multi-agent memory/authorisation decisions. They help test an adjacent temporal/governance reading skill and a realistic-source case intake workflow, not WAMBU's primary unsafe approval estimand.
- The PR title/body returned by the GitHub API may have been edited **after** closure. Predecision *comments* are filtered by `created_at < closed_at`, but the PR's own retrospective body is not a verified historical snapshot. The model may memorise a public PR outcome from pretraining. Therefore this study is not a leakage-proof prospective historical prediction benchmark.
- Public source snapshots can contain usernames and other public personal identifiers. Reviewer-visible cases exclude author identities, account metadata and source URLs; raw original evidence remains within a limited-retention Github Actions artifact rather than being committed to the repository.
- Three AI vendors do not constitute independent human reviewers. No AI opinion is allowed to set `HUMAN_ADJUDICATED`, `VALIDATED_NATURALISTIC_POLICY_ACTION`, `FULL_KNOWLEDGE_TRIAGE_REPLICATION` or `SCIENCE_APPROVED`.
- Factual merger/closure is never treated as normative validity or as independent expert gold, and no protected confirmatory split is inspected.
- This does not resolve the P07b requirement for independently authored actual operational policy actions and qualified blinded human adjudications. P08 original full-framework comparison remains blocked on model, corpus, budget and downstream parity.

## Expected evidence

- One GitHub Actions workflow with three stages: public collection, isolated AI-only OpenRouter review, detached offline evaluation.
- Two original evidence archives (blind inputs + full original source snapshots), one raw AI-only reviewer archive, one detached result archive.
- Explicit `PARTIAL` status for missing model responses or source/temporal provenance errors; source failures abort paid review.
- Final completion is **technical intake and AI-only retrospective simulation**, not scientific external reference validation or journal acceptance.

When these bounded tasks complete, the next eligible scientific milestone is gathering *actual operational decisions* and independently adjudicated human policy labels with a prospectively frozen rubric and valid event-time snapshots. Do not upgrade public PR dispositions into that dataset.
